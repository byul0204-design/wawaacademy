## 자기주도학습 수학학원은 일반 수업과 무엇이 다른가요?

**설명을 듣는 시간보다 학생이 스스로 푸는 시간이 길고, 그 시간이 잘 쓰였는지를 매번 확인한다는 점이 다릅니다.** 수학은 설명을 들을 때 이해한 것 같아도 혼자 다시 풀면 막히는 과목이라, 혼자 푸는 경험이 쌓여야 시험장에서 손이 움직입니다.

| 구분 | 설명 위주 수업 | 가경점 수업 |
| --- | --- | --- |
| 수업 흐름 | 선생님 설명 → 다 같이 문제 풀이 | 오늘 할 분량 확인 → 혼자 풀기 → 막힌 문제 질문 → 다시 풀기 |
| 진도 | 반 전체가 같은 진도 | 학생마다 학교·학년에 맞춘 진도 |
| 숙제 확인 | 했는지만 확인 | 어디서 막혔는지, 몇 번 만에 풀었는지 확인 |
| 결과 | 수업 시간에는 이해한 것 같음 | 혼자 풀 수 있는 문제가 늘어남 |

혼자 공부하는 습관을 집에서도 이어 가는 방법은 [자기주도학습 습관 글](/info/self-directed-learning-habit/)에 정리해 두었습니다.

## 고등 수학 개별지도는 무엇이 다른가요?

**고등학교는 학교마다 시험 문제의 난도와 교재가 크게 달라서, 같은 학년이라도 같은 진도로 묶기 어렵습니다.** 사대부고, 서원고, 청주외고처럼 가경동 학생들이 다니는 고등학교도 시험 범위와 부교재가 서로 다르기 때문에, 학생이 받아 온 시험 범위표와 학교 프린트를 기준으로 개별 진도를 짭니다.

- **고1**: 공통수학의 다항식, 방정식과 부등식, 경우의 수에서 중학교 개념이 빈 곳이 드러납니다. 빈 단원은 중학 과정으로 잠시 돌아가 메운 뒤 진도를 이어 갑니다.
- **고2·고3**: 선택 과목에 따라 배우는 내용이 달라 학생마다 교재와 진도를 따로 정합니다. 영어와 수학은 고3까지 관리할 수 있습니다.
- **내신 등급**: 지금 고등학교 내신은 5등급제로 바뀌어 한 문제 차이로 등급이 갈리기 쉽습니다. 제도 설명은 [내신 5등급제 글](/info/naesin-5-grade-system/)을 참고하세요.

### 가경동 자기주도학습 수학학원은 어디에 있나요?

### 중등 고등 개별지도는 수업 방식이 어떻게 다른가요?

중등은 학교별 시험 범위와 서술형에 맞춰 단원별로 진도를 잡고, 고등은 학교마다 다른 교재와 선택 과목에 맞춰 학생별로 교재와 진도를 따로 정합니다. 두 과정 모두 혼자 푸는 시간을 먼저 두고 막힌 문제를 질문하는 방식으로 수업합니다.

### 수학 말고 다른 과목도 배울 수 있나요?

영어는 초3부터 고3까지, 국어와 사회는 초1부터 고1까지 함께 관리할 수 있습니다. 과학 수업은 운영하지 않습니다.

### 주말에도 수업하나요?

주말 수업은 없고 평일 오후 2시 이후에 운영합니다. 학생의 학교 일정에 맞춰 평일 수업 요일과 시간을 정합니다.
