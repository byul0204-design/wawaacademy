**근의 공식**은 이차방정식 ax² + bx + c = 0(a ≠ 0)의 해를 계수 a, b, c만으로 바로 구하는 공식으로, **x = (−b ± √(b² − 4ac)) / 2a**입니다. 인수분해가 되지 않는 이차방정식도 근의 공식에 넣으면 항상 해를 구할 수 있어 중학교 3학년 이차방정식 단원의 핵심입니다. 다만 모든 문제를 근의 공식으로 풀면 계산이 길어지므로, **인수분해 → 제곱근 → 근의 공식** 순서로 먼저 쉬운 방법을 확인하는 것이 이차방정식 푸는법의 기본입니다.

<div class="tldr">
<span class="tldr-t">핵심 요약</span>
<ul>
<li>근의 공식: <b>x = (−b ± √(b² − 4ac)) / 2a</b></li>
<li>x의 계수가 짝수(b = 2b')이면 <b>짝수 근의 공식 x = (−b' ± √(b'² − ac)) / a</b>로 계산이 짧아집니다.</li>
<li>루트 안의 <b>b² − 4ac(판별식 D)</b>가 양수면 근이 두 개, 0이면 중근, 음수면 실수인 근이 없습니다.</li>
</ul>
</div>

## 이차방정식 푸는법, 어떤 순서로 하나요?

**식을 ax² + bx + c = 0 꼴로 정리한 뒤, 간단한 방법부터 차례로 시도합니다.**

<ol class="steps">
<li><b>정리하기</b><span>모든 항을 좌변으로 옮겨 ax² + bx + c = 0 꼴로 만들고, 계수가 분수나 소수면 양변에 같은 수를 곱해 정수로 바꿉니다.</span></li>
<li><b>인수분해 시도</b><span>x² − 5x + 6 = 0처럼 인수분해가 되면 (x − 2)(x − 3) = 0에서 x = 2 또는 x = 3입니다. 인수분해 공식은 <a href="/info/factorization-formula/">인수분해 공식 글</a>에 정리했습니다.</span></li>
<li><b>제곱근 이용</b><span>(x − 1)² = 5처럼 완전제곱 꼴이면 x − 1 = ±√5에서 x = 1 ± √5입니다.</span></li>
<li><b>근의 공식</b><span>위 방법이 안 되면 근의 공식을 씁니다. x의 계수가 짝수면 짝수 근의 공식을 먼저 떠올립니다.</span></li>
</ol>

## 근의 공식 사용법

ax² + bx + c = 0에서 **a, b, c를 부호까지 정확히 읽는 것**이 가장 중요합니다. 2x² + 3x − 1 = 0이면 a = 2, b = 3, c = −1입니다.

| 단계 | 계산 | 2x² + 3x − 1 = 0의 예 |
| --- | --- | --- |
| a, b, c 읽기 | 부호 포함 | a = 2, b = 3, c = −1 |
| 루트 안 계산 | b² − 4ac | 9 − 4 × 2 × (−1) = 17 |
| 공식에 넣기 | (−b ± √(b² − 4ac)) / 2a | (−3 ± √17) / 4 |

<div class="callout tip">
<span class="callout-t">가장 흔한 실수 두 가지</span>
<p>첫째, c가 음수일 때 −4ac의 부호를 놓치는 실수입니다. −4 × 2 × (−1)은 +8입니다. 둘째, 분모 2a를 −b에만 나누는 실수입니다. 분수 막대는 <b>−b ± √(…) 전체</b>를 나눕니다.</p>
</div>

## 근의 공식 유도 과정 (완전제곱식 이용)

근의 공식은 외우는 것이 아니라 **완전제곱식으로 만들어 제곱근을 구하는 과정**에서 나옵니다. 유도 과정을 쓰라는 서술형도 자주 나옵니다.

<ol class="flow">
<li><b>x²의 계수로 나누기</b><span>ax² + bx + c = 0의 양변을 a로 나누면 x² + (b/a)x + c/a = 0</span></li>
<li><b>상수항 옮기기</b><span>x² + (b/a)x = −c/a</span></li>
<li><b>완전제곱식 만들기</b><span>양변에 (b/2a)²을 더하면 (x + b/2a)² = (b² − 4ac) / 4a²</span></li>
<li><b>제곱근 구하기</b><span>x + b/2a = ±√(b² − 4ac) / 2a이므로 x = (−b ± √(b² − 4ac)) / 2a</span></li>
</ol>

3단계에서 더하는 (b/2a)²은 'x의 계수의 절반의 제곱'입니다. 완전제곱식을 만드는 원리는 이차함수의 꼭짓점을 구할 때도 그대로 쓰입니다.

## 짝수 근의 공식, 언제 쓰나요?

**x의 계수 b가 짝수일 때(b = 2b') 쓰면 약분 과정이 줄어듭니다.** 일반 근의 공식으로 풀어도 답은 같지만, 숫자가 작아져 계산 실수가 줄어듭니다.

<ul class="cards">
<li><span class="card-k">공식</span><b>x = (−b' ± √(b'² − ac)) / a</b><p>b' = b ÷ 2입니다. 분모가 2a가 아니라 a, 루트 안이 b'² − ac로 바뀝니다.</p></li>
<li><span class="card-k">예시 1</span><b>x² + 6x + 4 = 0</b><p>b' = 3이므로 x = −3 ± √(9 − 4) = −3 ± √5</p></li>
<li><span class="card-k">예시 2</span><b>3x² − 2x − 2 = 0</b><p>b' = −1이므로 x = (1 ± √(1 + 6)) / 3 = (1 ± √7) / 3</p></li>
<li><span class="card-k">확인</span><b>일반 공식과 같은 답</b><p>x² + 6x + 4 = 0을 일반 공식으로 풀면 (−6 ± √20) / 2 = (−6 ± 2√5) / 2 = −3 ± √5로 같습니다.</p></li>
</ul>

## 판별식으로 근의 개수 알기

근의 공식의 루트 안 **b² − 4ac를 판별식 D**라고 합니다. 근을 직접 구하지 않아도 D의 부호만 보면 근이 몇 개인지 알 수 있습니다.

| 판별식 | 근의 개수 | 예시 |
| --- | --- | --- |
| D > 0 | 서로 다른 두 근 | x² − 5x + 6 = 0 → D = 1 |
| D = 0 | 한 근(중근) | x² − 4x + 4 = 0 → D = 0, x = 2 |
| D < 0 | 실수인 근이 없음 | x² + x + 1 = 0 → D = −3 |

짝수 근의 공식을 쓸 때는 **D/4 = b'² − ac**로 판별해도 부호가 같습니다. 중학교에서는 D < 0이면 '근이 없다'고 배우고, 고등학교 1학년 공통수학에서는 이 경우를 '서로 다른 두 허근'으로 다룹니다.

## 확인 문제

여섯 문제로 확인해 보세요. 답을 먼저 정한 뒤 문항을 눌러 확인합니다.

<details class="reveal">
<summary>① x² − 5x + 6 = 0을 근의 공식으로 풀면?</summary>
<p><b>x = 3 또는 x = 2</b>. (5 ± √(25 − 24)) / 2 = (5 ± 1) / 2입니다. 인수분해 (x − 2)(x − 3) = 0과 같은 답입니다.</p>
</details>

<details class="reveal">
<summary>② 2x² + 3x − 1 = 0의 해는?</summary>
<p><b>x = (−3 ± √17) / 4</b>. b² − 4ac = 9 + 8 = 17입니다.</p>
</details>

<details class="reveal">
<summary>③ 짝수 근의 공식으로 x² + 6x + 4 = 0을 풀면?</summary>
<p><b>x = −3 ± √5</b>. b' = 3이므로 −3 ± √(9 − 4)입니다.</p>
</details>

<details class="reveal">
<summary>④ x² − 4x + 4 = 0의 근은 몇 개인가요?</summary>
<p><b>한 개(중근), x = 2</b>. D = 16 − 16 = 0입니다.</p>
</details>

<details class="reveal">
<summary>⑤ x² + x + 1 = 0은 실수인 근이 있나요?</summary>
<p><b>없습니다</b>. D = 1 − 4 = −3으로 음수입니다.</p>
</details>

<details class="reveal">
<summary>⑥ x² + kx + 9 = 0이 중근을 가질 때 k의 값은?</summary>
<p><b>k = 6 또는 k = −6</b>. D = k² − 36 = 0이므로 k² = 36입니다.</p>
</details>

②가 틀렸다면 c의 부호를, ③이 틀렸다면 b' = b ÷ 2를 다시 확인하세요. 근의 공식에 √가 많이 나오므로 제곱근 계산이 약하다면 함께 복습하는 것이 좋습니다. 같은 학년의 도형 단원은 [피타고라스 정리 글](/info/pythagorean-theorem/)에 정리해 두었습니다.

## 자주 묻는 질문

### 근의 공식은 중학교 몇 학년에서 배우나요?

중학교 3학년 1학기 이차방정식 단원에서 배웁니다. 판별식과 허근, 근과 계수의 관계는 고등학교 1학년 공통수학에서 더 자세히 다룹니다. 교과서마다 순서가 다를 수 있으니 목차를 확인하세요.

### 근의 공식을 꼭 외워야 하나요?

외워 두는 것이 좋지만, 유도 과정을 한 번 직접 따라 써 보면 훨씬 오래 기억됩니다. 완전제곱식을 만드는 원리를 이해하면 공식을 잊어도 다시 만들 수 있습니다.

### 짝수 근의 공식과 일반 근의 공식은 답이 다른가요?

답은 같습니다. 짝수 근의 공식은 x의 계수가 짝수일 때 약분 과정을 미리 줄여 둔 공식이라 계산이 짧고 실수가 적을 뿐입니다.

### 판별식이 음수면 문제가 틀린 건가요?

아닙니다. 판별식이 음수면 실수 범위에서 근이 없다는 뜻입니다. 중학교 문제에서는 '근이 없다'가 답이 되는 경우가 있고, 고등학교에서는 허근으로 답합니다.
