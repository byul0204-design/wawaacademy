**이차함수 꼭짓점**은 포물선 모양 그래프가 꺾여 방향이 바뀌는 점으로, 식이 **y = a(x − p)² + q** 꼴이면 꼭짓점은 **(p, q)**, 그래프의 축은 **x = p**입니다. 식이 y = ax² + bx + c 꼴로 주어지면 **완전제곱식으로 바꿔** (p, q)를 읽거나, 꼭짓점 x좌표 공식 **x = −b/2a**에 대입해 구합니다. 예를 들어 y = x² − 4x + 7은 (x − 2)² + 3으로 바꿀 수 있어 꼭짓점이 (2, 3)입니다.

<div class="tldr">
<span class="tldr-t">핵심 요약</span>
<ul>
<li><b>y = a(x − p)² + q</b>의 꼭짓점은 <b>(p, q)</b>입니다. 괄호 안이 x − 2면 p = 2, x + 2면 p = −2로 부호가 바뀝니다.</li>
<li>y = ax² + bx + c는 꼭짓점 x좌표가 <b>−b/2a</b>이고, 그 값을 식에 넣으면 y좌표가 나옵니다.</li>
<li><b>a &gt; 0이면 아래로 볼록</b>(꼭짓점에서 최솟값), <b>a &lt; 0이면 위로 볼록</b>(꼭짓점에서 최댓값)입니다.</li>
</ul>
</div>

## 이차함수 꼭짓점, 식 모양별로 바로 읽기

| 식의 모양 | 꼭짓점 | 축의 방정식 | 예 |
| --- | --- | --- | --- |
| y = ax² | (0, 0) | x = 0 (y축) | y = 3x² → (0, 0) |
| y = ax² + q | (0, q) | x = 0 | y = x² − 5 → (0, −5) |
| y = a(x − p)² | (p, 0) | x = p | y = 2(x + 1)² → (−1, 0) |
| y = a(x − p)² + q | (p, q) | x = p | y = 2(x − 3)² + 1 → (3, 1) |

<div class="callout warn">
<span class="callout-t">가장 많이 틀리는 부분: 괄호 안의 부호</span>
<p>y = 2(x + 1)²은 x − (−1)로 읽어야 해서 꼭짓점 x좌표가 <b>−1</b>입니다. 괄호 밖의 q는 보이는 부호 그대로 쓰고, 괄호 안의 p만 부호를 바꿔 읽는다고 기억하세요.</p>
</div>

## 이차함수 꼭짓점 구하기: 완전제곱식으로 바꾸는 4단계

y = ax² + bx + c는 그대로는 꼭짓점이 보이지 않아서, **y = a(x − p)² + q 꼴로 바꾸는 과정**이 필요합니다. y = −2x² + 8x − 5로 따라가 보겠습니다.

<ol class="steps">
<li><b>x가 있는 항을 a로 묶기</b><span>y = −2(x² − 4x) − 5. 상수항 −5는 괄호 밖에 둡니다.</span></li>
<li><b>x 계수의 절반을 제곱해 더하고 빼기</b><span>괄호 안 x의 계수 −4의 절반은 −2, 제곱하면 4입니다. y = −2(x² − 4x + 4 − 4) − 5</span></li>
<li><b>완전제곱식 만들기</b><span>y = −2{(x − 2)² − 4} − 5. x² − 4x + 4 = (x − 2)²입니다. 이 부분이 막히면 <a href="/info/factorization-formula/">인수분해 공식 글</a>을 먼저 보세요.</span></li>
<li><b>괄호를 풀어 정리하기</b><span>y = −2(x − 2)² + 8 − 5 = −2(x − 2)² + 3. 꼭짓점은 <b>(2, 3)</b>, 축은 x = 2입니다.</span></li>
</ol>

2단계에서 빼 준 4가 괄호 밖으로 나올 때 **a(여기서는 −2)를 곱해서** 나온다는 점을 놓치기 쉽습니다. −4가 아니라 +8이 되는 이유입니다.

## 꼭짓점 좌표 공식 −b/2a, 언제 쓰나요?

완전제곱식을 매번 만들기 번거로울 때는 **꼭짓점 x좌표 = −b/2a**를 바로 쓰고, 그 x값을 원래 식에 넣어 y좌표를 구합니다.

- y = x² + 6x + 5: x = −6/(2×1) = −3, y = 9 − 18 + 5 = −4 → 꼭짓점 **(−3, −4)**
- y = ½x² + 2x + 1: x = −2/(2×½) = −2, y = 2 − 4 + 1 = −1 → 꼭짓점 **(−2, −1)**

y좌표는 공식 **(4ac − b²)/4a**로도 구할 수 있지만, x값을 식에 대입하는 쪽이 계산 실수가 적습니다. 공식 −b/2a는 [근의 공식](/info/quadratic-formula/)에 나오는 −b/2a와 같은 값이라, 포물선의 축이 두 근의 한가운데를 지난다는 뜻이기도 합니다.

## a의 부호와 그래프의 폭, 평행이동

<ul class="cards cards-2">
<li><span class="card-k">a &gt; 0</span><b>아래로 볼록</b><p>꼭짓점이 가장 낮은 점이라 꼭짓점의 y좌표가 <b>최솟값</b>입니다. 최댓값은 없습니다.</p></li>
<li><span class="card-k">a &lt; 0</span><b>위로 볼록</b><p>꼭짓점이 가장 높은 점이라 꼭짓점의 y좌표가 <b>최댓값</b>입니다. 최솟값은 없습니다.</p></li>
<li><span class="card-k">|a|가 클수록</span><b>폭이 좁아짐</b><p>y = 3x²은 y = x²보다 폭이 좁고, y = ⅓x²은 더 넓습니다. 부호와 상관없이 절댓값만 비교합니다.</p></li>
<li><span class="card-k">평행이동</span><b>y = ax² → y = a(x − p)² + q</b><p>y = ax²을 x축 방향으로 p, y축 방향으로 q만큼 옮기면 꼭짓점이 (0, 0)에서 (p, q)로 이동합니다. a는 그대로라 모양과 폭은 같습니다.</p></li>
</ul>

일차함수처럼 그래프의 y절편도 함께 묻는 경우가 많은데, y = ax² + bx + c의 **y절편은 c**입니다. 일차함수 그래프의 기울기·절편 개념은 [일차함수 그래프 글](/info/linear-function-graph/)에 정리해 두었습니다.

## 꼭짓점을 알 때 이차함수 식 세우기

꼭짓점 (p, q)를 알면 식을 **y = a(x − p)² + q**로 놓고, 지나는 다른 한 점을 대입해 a를 구합니다.

| 단계 | 예: 꼭짓점 (1, −3), 점 (2, −1)을 지나는 그래프 |
| --- | --- |
| ① 꼭짓점으로 식 놓기 | y = a(x − 1)² − 3 |
| ② 다른 점 대입 | −1 = a(2 − 1)² − 3 |
| ③ a 구하기 | −1 = a − 3, a = 2 |
| ④ 완성 | y = 2(x − 1)² − 3 |

## 확인 문제

여섯 문제로 확인해 보세요. 답을 먼저 정한 뒤 문항을 눌러 확인합니다.

<details class="reveal">
<summary>① y = −(x + 1)² + 4의 꼭짓점과 축은?</summary>
<p><b>꼭짓점 (−1, 4), 축 x = −1</b>. 괄호 안 x + 1은 x − (−1)이므로 p = −1입니다. a = −1 &lt; 0이라 꼭짓점에서 최댓값 4를 가집니다.</p>
</details>

<details class="reveal">
<summary>② y = x² + 6x + 5를 y = a(x − p)² + q 꼴로 바꾸면?</summary>
<p><b>y = (x + 3)² − 4</b>. x 계수 6의 절반 3을 제곱한 9를 더하고 빼면 (x + 3)² − 9 + 5가 됩니다. 꼭짓점은 (−3, −4)입니다.</p>
</details>

<details class="reveal">
<summary>③ y = 3x² − 12x + 10의 꼭짓점은?</summary>
<p><b>(2, −2)</b>. x = −(−12)/(2×3) = 2, y = 12 − 24 + 10 = −2입니다.</p>
</details>

<details class="reveal">
<summary>④ 꼭짓점이 (1, −3)이고 점 (2, −1)을 지나는 이차함수의 식은?</summary>
<p><b>y = 2(x − 1)² − 3</b>. y = a(x − 1)² − 3에 (2, −1)을 넣으면 a = 2입니다.</p>
</details>

<details class="reveal">
<summary>⑤ y = 2x²의 그래프를 x축 방향으로 −3, y축 방향으로 5만큼 평행이동한 그래프의 꼭짓점은?</summary>
<p><b>(−3, 5)</b>. 식은 y = 2(x + 3)² + 5입니다.</p>
</details>

<details class="reveal">
<summary>⑥ y = −x² + 4x + k의 꼭짓점이 x축 위에 있을 때 k의 값은?</summary>
<p><b>k = −4</b>. y = −(x − 2)² + 4 + k이고, 꼭짓점이 x축 위에 있으려면 꼭짓점의 y좌표 4 + k = 0이어야 합니다.</p>
</details>

①·⑤를 틀렸다면 괄호 안의 부호와 평행이동을, ②·③이라면 완전제곱식 변형과 −b/2a 공식을, ④·⑥이라면 꼭짓점으로 식을 세우는 방법을 다시 확인하세요. 이차함수와 같은 학년에 배우는 [피타고라스 정리](/info/pythagorean-theorem/)도 함께 복습하면 좋습니다.

## 자주 묻는 질문

### 이차함수 꼭짓점은 몇 학년에서 배우나요?

중학교 3학년에서 y = a(x − p)² + q의 꼭짓점과 평행이동, y = ax² + bx + c를 완전제곱식으로 바꾸는 방법을 배웁니다. 고등학교 1학년 공통수학에서는 이를 바탕으로 이차함수의 최댓값·최솟값과 이차방정식과의 관계를 다룹니다.

### 꼭짓점 좌표 공식만 외워도 되나요?

x좌표 −b/2a는 외워 두면 빠르지만, 시험 서술형에서는 완전제곱식으로 바꾸는 과정을 쓰라고 하는 경우가 많습니다. 두 방법을 모두 연습하고, 공식은 검산용으로 쓰는 것을 권합니다.

### 꼭짓점과 최댓값·최솟값은 어떤 관계인가요?

a가 양수이면 그래프가 아래로 볼록해서 꼭짓점의 y좌표가 최솟값, a가 음수이면 위로 볼록해서 꼭짓점의 y좌표가 최댓값입니다. 이때 최댓값·최솟값을 갖는 x의 값은 꼭짓점의 x좌표입니다.

### 그래프의 폭은 무엇으로 정해지나요?

x²의 계수 a의 절댓값으로 정해집니다. 절댓값이 클수록 폭이 좁고, 작을수록 넓습니다. p와 q는 위치만 바꾸고 폭에는 영향을 주지 않습니다.
