**일차함수 y = ax + b의 그래프**는 직선이고, **a(기울기)는 직선이 얼마나 기울었는지**, **b(y절편)는 직선이 y축과 만나는 위치**를 정합니다. 그래서 a와 b 두 숫자만 보면 그래프를 그릴 수 있고, 반대로 그래프만 보고 식을 세울 수도 있습니다. 중학교 2학년 일차함수 단원의 문제는 대부분 이 두 숫자를 구하거나 해석하는 문제입니다.

<div class="tldr">
<span class="tldr-t">핵심 요약</span>
<ul>
<li>기울기는 <b>(y의 값의 증가량) ÷ (x의 값의 증가량)</b>이고, 직선 위 어느 두 점을 골라도 같습니다.</li>
<li>y절편은 <b>x = 0일 때의 y값(b)</b>, x절편은 <b>y = 0일 때의 x값(−b/a)</b>입니다.</li>
<li>두 직선은 <b>기울기가 같고 y절편이 다르면 평행</b>, 기울기와 y절편이 모두 같으면 <b>일치</b>합니다.</li>
</ul>
</div>

### 두 점을 알 때 기울기 구하기

두 점 (x₁, y₁), (x₂, y₂)를 지나는 직선의 기울기는 **(y₂ − y₁) ÷ (x₂ − x₁)**입니다. 점 (1, 3)과 (3, 7)을 지나면 (7 − 3) ÷ (3 − 1) = 2입니다. 빼는 순서를 분자와 분모에서 똑같이 맞추기만 하면 어느 점을 먼저 써도 답이 같습니다.

## 일차함수 그래프 그리는 세 가지 방법

<ol class="steps">
<li><b>두 점을 찾아 잇기</b><span>x에 계산하기 쉬운 값 두 개를 넣어 점 두 개를 구한 뒤 직선으로 잇습니다. y = 2x + 1이면 x = 0일 때 (0, 1), x = 1일 때 (1, 3)입니다.</span></li>
<li><b>x절편과 y절편 잇기</b><span>y = 0을 넣어 x절편, x = 0을 넣어 y절편을 구하고 두 점을 잇습니다. y = −3x + 6이면 (2, 0)과 (0, 6)을 이으면 됩니다.</span></li>
<li><b>y절편에서 기울기만큼 이동하기</b><span>y축 위의 점 (0, b)를 찍고, 오른쪽으로 1칸, 위로 a칸 간 점을 찍어 잇습니다. 기울기가 −2라면 오른쪽 1칸, 아래로 2칸입니다.</span></li>
</ol>

<div class="callout tip">
<span class="callout-t">기울기가 분수일 때</span>

## 그래프의 성질과 평행이동

<ul class="cards">
<li><span class="card-k">a &gt; 0</span><b>오른쪽 위로 올라감</b><p>x의 값이 커지면 y의 값도 커집니다. y = 2x + 1처럼 기울기가 양수인 그래프입니다.</p></li>
<li><span class="card-k">a &lt; 0</span><b>오른쪽 아래로 내려감</b><p>x의 값이 커지면 y의 값은 작아집니다. y = −x + 3처럼 기울기가 음수인 그래프입니다.</p></li>
<li><span class="card-k">|a|</span><b>클수록 가파름</b><p>기울기의 절댓값이 클수록 그래프가 y축에 가까워집니다. y = 3x는 y = x보다 가파릅니다.</p></li>
<li><span class="card-k">평행이동</span><b>b만큼 위아래로</b><p>y = ax의 그래프를 y축 방향으로 b만큼 평행이동하면 y = ax + b가 됩니다. 기울기는 그대로입니다.</p></li>
</ul>

### 평행과 일치 조건

두 일차함수 y = ax + b와 y = cx + d의 그래프는 다음과 같이 구별합니다.

- **평행**: 기울기가 같고 y절편이 다를 때 (a = c, b ≠ d). 두 직선은 만나지 않습니다.
- **일치**: 기울기와 y절편이 모두 같을 때 (a = c, b = d). 두 직선이 완전히 겹칩니다.
- **한 점에서 만남**: 기울기가 다를 때 (a ≠ c).

## 그래프로 a와 b의 부호 판별하기

그래프 그림만 주고 a, b의 부호를 묻는 문제는 두 가지만 보면 풀립니다. **기울어진 방향으로 a**, **y축과 만나는 위치로 b**를 판단합니다.

| 그래프 모양 | a의 부호 | b의 부호 |
| --- | --- | --- |
| 오른쪽 위로, y축의 위쪽에서 만남 | + | + |
| 오른쪽 위로, y축의 아래쪽에서 만남 | + | − |
| 오른쪽 아래로, y축의 위쪽에서 만남 | − | + |
| 오른쪽 아래로, y축의 아래쪽에서 만남 | − | − |

## 확인 문제

다섯 문제로 확인해 보세요. 답을 먼저 정한 뒤 문항을 눌러 맞혔는지 봅니다.

<details class="reveal">
<summary>① 두 점 (1, 3), (3, 7)을 지나는 일차함수의 식은?</summary>
<p><b>y = 2x + 1</b>. 기울기는 (7 − 3) ÷ (3 − 1) = 2이고, y = 2x + b에 (1, 3)을 넣으면 3 = 2 + b이므로 b = 1입니다.</p>
</details>

<details class="reveal">
<summary>② y = −3x + 6의 x절편과 y절편은?</summary>
<p><b>x절편 2, y절편 6</b>. y = 0을 넣으면 0 = −3x + 6에서 x = 2이고, x = 0을 넣으면 y = 6입니다.</p>
</details>

<details class="reveal">
<summary>③ y = 2x − 1의 그래프와 평행하고 y절편이 4인 직선의 식은?</summary>
<p><b>y = 2x + 4</b>. 평행하면 기울기가 같으므로 기울기는 2, y절편은 4입니다.</p>
</details>

<details class="reveal">
<summary>④ y = ax + b의 그래프가 오른쪽 아래로 내려가고 y축의 위쪽에서 만날 때 a, b의 부호는?</summary>
<p><b>a &lt; 0, b &gt; 0</b>. 오른쪽 아래로 내려가므로 기울기는 음수, y축의 위쪽에서 만나므로 y절편은 양수입니다.</p>
</details>

<details class="reveal">
<summary>⑤ y = 3x의 그래프를 y축 방향으로 −2만큼 평행이동한 식은?</summary>
<p><b>y = 3x − 2</b>. y축 방향으로 평행이동하면 기울기는 그대로이고 상수항에 −2가 더해집니다.</p>
</details>

틀린 문항이 ①, ②라면 계산 순서를, ③~⑤라면 기울기와 y절편이 각각 무엇을 바꾸는지를 다시 확인하세요.

## 자주 묻는 질문

### 일차함수 그래프는 중학교 몇 학년에서 배우나요?

중학교 2학년 수학에서 배웁니다. 1학년의 좌표평면과 정비례·반비례 그래프를 바탕으로 하고, 같은 학년에서 일차함수와 일차방정식의 관계, 연립방정식의 해와 두 그래프의 교점으로 이어집니다.

### 기울기와 y절편 중 무엇을 먼저 구해야 하나요?

보통 기울기를 먼저 구합니다. 두 점이 주어지면 기울기를 계산한 뒤 y = ax + b에 한 점을 넣어 b를 구하는 순서가 가장 실수가 적습니다. y절편이 이미 주어졌다면 기울기만 구하면 됩니다.

### x절편은 왜 −b/a인가요?

x절편은 그래프가 x축과 만나는 점이므로 y = 0을 넣습니다. 0 = ax + b를 x에 대해 풀면 x = −b/a가 됩니다. 공식을 외우기보다 y에 0을 넣어 직접 푸는 편이 부호 실수를 줄입니다.

### y = 3처럼 x가 없는 식도 일차함수인가요?

아닙니다. y = 3은 x의 값과 관계없이 y가 늘 3인 직선으로, x축에 평행한 그래프입니다. 일차함수는 y = ax + b에서 a ≠ 0이어야 하므로 y = 3은 일차함수가 아닙니다. 다만 일차방정식의 그래프 단원에서 함께 다룹니다.
