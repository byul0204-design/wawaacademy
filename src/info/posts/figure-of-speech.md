**표현법**은 글쓴이가 말하고 싶은 것을 더 생생하고 인상 깊게 전하려고 쓰는 방법이며, 크게 **비유법·강조법·변화법** 세 갈래로 나뉩니다. 이 가운데 가장 많이 출제되는 **비유법**은 말하려는 대상(원관념)을 다른 대상(보조관념)에 빗대어 표현하는 방법입니다. "내 마음은 호수요"에서 원관념은 '내 마음', 보조관념은 '호수'입니다. 시험에서는 특히 **직유법과 은유법**, **의인법과 활유법**을 구분하는 문제가 자주 나오는데, 각각 기준 하나만 알면 헷갈리지 않습니다.

<div class="tldr">
<span class="tldr-t">핵심 요약</span>
<ul>
<li><b>비유법</b>: 다른 대상에 빗대기 (직유·은유·의인·활유·대유)</li>
<li><b>강조법</b>: 뜻을 세게 드러내기 (과장·반복·영탄·점층·대조)</li>
<li><b>변화법</b>: 문장에 변화를 주기 (설의·도치·대구·반어·역설)</li>
<li>직유는 <b>"~같이, ~처럼, ~듯"</b>이 있고 은유는 없음 / 의인은 <b>사람처럼</b>, 활유는 <b>생물처럼</b></li>
</ul>
</div>

## 비유법 종류와 예시

| 비유법 | 뜻 | 예시 |
| --- | --- | --- |
| 직유법 | "~같이, ~처럼, ~듯"으로 직접 빗댐 | 쟁반같이 둥근 달 / 별처럼 반짝이는 눈 |
| 은유법 | "A는 B이다"처럼 연결어 없이 빗댐 | 내 마음은 호수요 / 시간은 금이다 |
| 의인법 | 사람이 아닌 것을 사람처럼 표현 | 꽃이 웃는다 / 바람이 속삭인다 |
| 활유법 | 생명 없는 것을 살아 있는 동물처럼 표현 | 울부짖는 바다 / 산이 꿈틀거린다 |
| 대유법 | 일부나 특징으로 전체를 나타냄 | 빵이 아니면 살 수 없다(빵 → 먹을 것) / 펜은 칼보다 강하다 |

## 직유법 은유법 차이

**연결하는 말("~같이, ~처럼, ~듯, ~양")이 있으면 직유법, 없이 "A는 B다"로 바로 이으면 은유법입니다.**

<ol class="steps">
<li><b>연결어 찾기</b><span>"그녀의 웃음은 꽃처럼 환했다" → '처럼'이 있으므로 직유법입니다.</span></li>
<li><b>없으면 은유</b><span>"그녀의 웃음은 한 송이 꽃이다" → 연결어 없이 웃음을 꽃이라고 단정하므로 은유법입니다.</span></li>
<li><b>함정 주의</b><span>"그는 아버지처럼 키가 크다"는 실제 두 사람을 비교한 말이라 비유가 아닙니다. 서로 다른 성질의 대상을 빗댈 때만 비유법입니다.</span></li>
</ol>

## 의인법 활유법 차이

**사람만 할 수 있는 행동·감정을 주면 의인법, 동물처럼 살아 움직이게 하면 활유법입니다.** 기준은 "그 행동을 사람만 하는가"입니다.

<ul class="cards cards-2">
<li><span class="card-k">의인법</span><b>꽃이 웃는다</b><p>웃음은 사람의 표정이므로 의인법입니다. "나무가 손을 흔든다", "달님이 미소 짓는다"도 같습니다.</p></li>
<li><span class="card-k">활유법</span><b>울부짖는 바다</b><p>울부짖음은 짐승도 하는 행동이라 활유법으로 봅니다. "산이 꿈틀거린다", "기차가 숨을 몰아쉰다"도 활유입니다.</p></li>
<li><span class="card-k">헷갈릴 때</span><b>사람만 하는가?</b><p>말하다·웃다·생각하다처럼 사람에게만 어울리면 의인, 움직이다·울부짖다처럼 동물도 하면 활유입니다.</p></li>
<li><span class="card-k">시험 팁</span><b>교과서 기준 확인</b><p>교과서나 학교에 따라 활유를 의인에 포함해 설명하기도 하니, 학교 수업 노트의 기준을 따르세요.</p></li>
</ul>

## 강조법과 변화법 차이

**강조법은 뜻을 더 세게 느끼게 하고, 변화법은 문장의 모양을 바꿔 단조로움을 피합니다.**

| 갈래 | 표현법 | 예시 |
| --- | --- | --- |
| 강조법 | 과장법 | 눈물이 바다를 이루었다 |
| | 반복법 | 산에 산에 산에는 산에 피는 꽃은 |
| | 영탄법 | 아, 아름다운 강산이여! |
| | 점층법 | 한 사람이, 열 사람이, 온 마을이 |
| | 대조법 | 인생은 짧고 예술은 길다 |
| 변화법 | 설의법 | 이보다 더 좋을 수 있을까? (답이 정해진 물음) |
| | 도치법 | 보고 싶다, 너를 |
| | 대구법 | 낮말은 새가 듣고 밤말은 쥐가 듣는다 |
| | 반어법 | (지각한 친구에게) 참 일찍도 왔다 |
| | 역설법 | 소리 없는 아우성 |

반어법은 **말과 속뜻이 반대**이고, 역설법은 **표현 자체가 모순**이라는 점이 다릅니다. 소설에서 서술자의 위치를 따지는 [소설 시점](/info/novel-point-of-view/)과 함께 문학 단원의 기본 개념이니 같이 익혀 두세요.

## 확인 문제

여섯 문제로 확인해 보세요. 답을 먼저 정한 뒤 문항을 눌러 확인합니다.

<details class="reveal">
<summary>① "호수 같은 그대의 눈"에 쓰인 비유법은?</summary>
<p><b>직유법</b>. '같은'이라는 연결어로 눈을 호수에 직접 빗댔습니다.</p>
</details>

<details class="reveal">
<summary>② "그대의 눈은 호수다"에 쓰인 비유법은?</summary>
<p><b>은유법</b>. 연결어 없이 눈을 호수라고 단정했습니다.</p>
</details>

<details class="reveal">
<summary>③ "봄바람이 창문을 두드리며 나를 부른다"에 쓰인 표현법은?</summary>
<p><b>의인법</b>. 부르는 것은 사람의 행동입니다.</p>
</details>

<details class="reveal">
<summary>④ "성난 파도가 으르렁거린다"는 의인법일까요, 활유법일까요?</summary>
<p><b>활유법</b>. 으르렁거림은 동물의 행동이라 생명 없는 파도를 살아 있는 짐승처럼 표현했습니다.</p>
</details>

<details class="reveal">
<summary>⑤ "소리 없는 아우성"에 쓰인 표현법은?</summary>
<p><b>역설법</b>. 소리가 없는 아우성이라는 모순된 표현 속에 의미를 담았습니다.</p>
</details>

<details class="reveal">
<summary>⑥ "보고 싶다, 너를"에 쓰인 표현법은?</summary>
<p><b>도치법</b>. "너를 보고 싶다"의 순서를 바꿔 감정을 강조했습니다.</p>
</details>

①·②를 틀렸다면 직유법 은유법 차이를, ③·④라면 의인법 활유법 차이를, ⑤·⑥이라면 강조법과 변화법 표를 다시 확인하세요. 같은 국어 단원의 [높임법](/info/korean-honorifics/), [합성어 파생어](/info/compound-derived-word/)도 함께 복습하면 좋습니다.

## 자주 묻는 질문

### 비유법 종류에는 무엇이 있나요?

대표적으로 직유법, 은유법, 의인법, 활유법, 대유법이 있습니다. 교과서에 따라 풍유법, 상징 등을 함께 다루기도 합니다.

### 직유법 은유법 차이를 한 줄로 정리하면?

"~같이, ~처럼, ~듯" 같은 연결어가 있으면 직유법, 없이 "A는 B다"로 이으면 은유법입니다.

### 의인법 활유법 차이는 무엇인가요?

사람만 하는 행동·감정을 주면 의인법, 동물처럼 살아 움직이게 하면 활유법입니다.

### 강조법 변화법 차이는?

강조법은 과장·반복·영탄처럼 뜻을 세게 드러내고, 변화법은 설의·도치·대구처럼 문장 모양에 변화를 주어 단조로움을 피합니다.
