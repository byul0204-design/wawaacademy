**피타고라스 정리**는 **직각삼각형에서 빗변의 길이의 제곱은 나머지 두 변의 길이의 제곱의 합과 같다**는 정리입니다. 직각을 낀 두 변을 a, b, 직각과 마주 보는 가장 긴 변(빗변)을 c라고 하면 **a² + b² = c²**가 성립합니다. 두 변의 길이만 알면 나머지 한 변을 구할 수 있고, 거꾸로 세 변의 길이로 직각삼각형인지 판별할 수도 있어 도형 문제 전반에 쓰입니다.

<div class="tldr">
<span class="tldr-t">핵심 요약</span>
<ul>
<li>공식은 <b>a² + b² = c²</b>이고, c는 반드시 <b>직각과 마주 보는 빗변</b>입니다.</li>
<li><b>3·4·5, 5·12·13, 8·15·17</b>처럼 세 변이 모두 자연수인 피타고라스 수를 외워 두면 계산이 빨라집니다.</li>
<li>가장 긴 변을 c라 할 때 <b>c² = a² + b²이면 직각, c²가 작으면 예각, 크면 둔각삼각형</b>입니다.</li>
</ul>
</div>

공식은 구하려는 변에 따라 아래처럼 바꿔 씁니다.

| 구하려는 것 | 식 | 예 (두 변이 주어졌을 때) |
| --- | --- | --- |
| 빗변 c | c² = a² + b² | a = 6, b = 8 → c² = 100 → c = 10 |
| 직각을 낀 변 a | a² = c² − b² | c = 13, b = 12 → a² = 25 → a = 5 |
| 직각을 낀 변 b | b² = c² − a² | c = 17, a = 8 → b² = 225 → b = 15 |

## 피타고라스 정리 증명 (넓이를 이용한 방법)

피타고라스 정리의 증명 방법은 수백 가지가 알려져 있습니다. 중학교에서 가장 많이 다루는 것은 **정사각형의 넓이를 두 가지로 계산하는 방법**입니다.

<ol class="steps">
<li><b>큰 정사각형을 만든다</b><span>한 변의 길이가 a + b인 정사각형 안에, 직각을 낀 두 변이 a, b이고 빗변이 c인 직각삼각형 4개를 네 모서리에 돌려 배치합니다. 가운데에는 한 변이 c인 정사각형이 생깁니다.</span></li>
<li><b>넓이를 두 가지로 쓴다</b><span>큰 정사각형 전체로 보면 (a + b)², 조각으로 보면 가운데 정사각형 c²과 삼각형 4개 4 × (ab ÷ 2) = 2ab의 합입니다.</span></li>
<li><b>두 식을 같다고 놓는다</b><span>(a + b)² = c² + 2ab에서 왼쪽을 펼치면 a² + 2ab + b² = c² + 2ab이고, 양변의 2ab를 지우면 a² + b² = c²가 됩니다.</span></li>
</ol>

가운데 사각형이 정사각형인 이유를 설명하라는 서술형도 나옵니다. 네 변이 모두 c이고, 한 꼭짓점에 모인 세 각 가운데 두 각의 합이 직각삼각형의 두 예각의 합인 90°라서 나머지 한 각도 90°가 된다는 점을 쓰면 됩니다.

## 자주 나오는 피타고라스 수

세 변의 길이가 모두 자연수인 직각삼각형의 세 수를 **피타고라스 수**라고 합니다. 아래 수는 외워 두면 시험에서 계산 시간을 크게 줄여 줍니다.

<ul class="cards">
<li><span class="card-k">기본</span><b>3, 4, 5</b><p>9 + 16 = 25. 두 배인 6, 8, 10과 세 배인 9, 12, 15도 모두 피타고라스 수입니다.</p></li>
<li><span class="card-k">자주 나옴</span><b>5, 12, 13</b><p>25 + 144 = 169. 두 배인 10, 24, 26도 함께 기억하세요.</p></li>
<li><span class="card-k">자주 나옴</span><b>8, 15, 17</b><p>64 + 225 = 289. 빗변 17이 보이면 바로 떠올리면 됩니다.</p></li>
<li><span class="card-k">가끔 나옴</span><b>7, 24, 25 / 20, 21, 29</b><p>49 + 576 = 625, 400 + 441 = 841. 숫자가 커서 계산 실수가 잦은 조합입니다.</p></li>
</ul>

피타고라스 수에 같은 수를 곱해도 피타고라스 수가 됩니다. 그래서 세 변이 모두 짝수라면 2로 나눠 기본 조합인지 먼저 확인하는 습관을 들이면 좋습니다.

## 직각삼각형인지 판별하기 (정리의 역)

세 변의 길이가 주어지면 피타고라스 정리를 거꾸로 써서 어떤 삼각형인지 알 수 있습니다. 세 변 가운데 **가장 긴 변을 c**로 놓고 비교합니다.

| 비교 결과 | 삼각형의 종류 | 예 |
| --- | --- | --- |
| c² = a² + b² | 직각삼각형 | 9, 12, 15 → 225 = 81 + 144 |
| c² < a² + b² | 예각삼각형 | 4, 5, 6 → 36 < 16 + 25 |
| c² > a² + b² | 둔각삼각형 | 3, 4, 6 → 36 > 9 + 16 |

## 피타고라스 정리 활용 문제 유형

- **직사각형의 대각선**: 가로와 세로가 직각을 낀 두 변, 대각선이 빗변입니다. 가로 9, 세로 12면 대각선은 15입니다.
- **사다리와 벽**: 벽에 기댄 사다리는 빗변, 벽의 높이와 바닥까지의 거리가 직각을 낀 두 변입니다.
- **좌표평면의 두 점 사이 거리**: 두 점의 x좌표 차와 y좌표 차를 직각을 낀 두 변으로 보고 빗변을 구합니다. 고등학교 두 점 사이의 거리 공식의 출발점입니다.
- **입체도형의 대각선과 높이**: 직육면체의 대각선, 원뿔의 높이처럼 입체 속에 숨은 직각삼각형을 찾아 두 번 적용하는 문제입니다.

제곱근을 배우기 전에는 답이 자연수로 나오는 문제 위주로, 제곱근을 배운 뒤에는 정삼각형의 높이처럼 답이 √로 나오는 문제로 넓어집니다. 좌표평면 문제가 낯설다면 [일차함수 그래프 글](/info/linear-function-graph/)의 좌표 개념을 먼저 복습하세요.

## 확인 문제

다섯 문제로 확인해 보세요. 답을 먼저 정한 뒤 문항을 눌러 맞혔는지 봅니다.

<details class="reveal">
<summary>① 직각을 낀 두 변이 6, 8인 직각삼각형의 빗변의 길이는?</summary>
<p><b>10</b>. 6² + 8² = 36 + 64 = 100이므로 빗변은 10입니다. 3, 4, 5의 두 배입니다.</p>
</details>

<details class="reveal">
<summary>② 빗변이 13, 한 변이 5인 직각삼각형의 나머지 한 변은?</summary>
<p><b>12</b>. 13² − 5² = 169 − 25 = 144이므로 12입니다.</p>
</details>

<details class="reveal">
<summary>③ 세 변이 7, 24, 25인 삼각형은 직각삼각형인가요?</summary>
<p><b>네</b>. 가장 긴 변 25의 제곱 625가 7² + 24² = 49 + 576 = 625와 같으므로 직각삼각형입니다.</p>
</details>

<details class="reveal">
<summary>④ 세 변이 4, 5, 6인 삼각형은 어떤 삼각형인가요?</summary>
<p><b>예각삼각형</b>. 6² = 36이 4² + 5² = 41보다 작으므로 예각삼각형입니다.</p>
</details>

<details class="reveal">
<summary>⑤ 가로 9cm, 세로 12cm인 직사각형의 대각선의 길이는?</summary>
<p><b>15cm</b>. 9² + 12² = 81 + 144 = 225이므로 대각선은 15cm입니다.</p>
</details>

틀린 문제가 ①, ②라면 빗변을 c에 제대로 넣었는지를, ③, ④라면 가장 긴 변을 골라 비교했는지를 다시 확인하세요. 같은 도형 단원의 [삼각형의 합동 조건](/info/triangle-congruence-conditions/)도 함께 복습하면 증명 서술형에 도움이 됩니다.

## 자주 묻는 질문

### 피타고라스 정리는 중학교 몇 학년에서 배우나요?

현재 교육과정에서는 보통 중학교 2학년 2학기 도형 단원에서 배웁니다. 이 시기에는 아직 제곱근을 배우지 않아 답이 자연수인 문제를 주로 다루고, 3학년에서 제곱근과 삼각비를 배우며 활용이 넓어집니다. 교과서마다 단원 순서가 다를 수 있으니 목차를 확인하세요.

### 피타고라스 정리는 모든 삼각형에 쓸 수 있나요?

아닙니다. 피타고라스 정리는 직각삼각형에서만 성립합니다. 직각이 없는 삼각형은 정리의 역을 이용해 예각인지 둔각인지 판별하는 데만 쓸 수 있습니다.

### 피타고라스 수를 꼭 외워야 하나요?

외우지 않아도 풀 수는 있지만, 3·4·5, 5·12·13, 8·15·17 정도는 외워 두는 것을 권합니다. 시험에서는 이 조합과 그 배수가 반복해서 나와 계산 시간을 줄이고 실수를 막아 줍니다.

### 빗변을 구할 때 제곱근이 나오면 어떻게 하나요?

직각을 낀 두 변이 1, 2처럼 피타고라스 수가 아니면 빗변이 √5처럼 제곱근으로 나옵니다. 제곱근을 배우기 전이라면 문제에서 답이 자연수가 되도록 주어지는 경우가 많고, 제곱근을 배운 뒤에는 √를 그대로 답으로 씁니다.
