**합성어**는 실질적인 뜻을 가진 **어근과 어근**이 만나 만든 단어이고, **파생어**는 어근에 뜻을 더하거나 품사를 바꾸는 **접사**가 붙어 만든 단어입니다. "밤나무"는 밤과 나무 두 어근이 만났으니 합성어, "풋사과"는 어근 사과에 접두사 풋-이 붙었으니 파생어입니다. 합성어 파생어 구분법의 핵심은 단어를 둘로 나눴을 때 **두 부분이 모두 혼자 뜻을 가지는지**, 아니면 **한쪽이 혼자 쓰이지 못하는 접사인지** 확인하는 것입니다.

<div class="tldr">
<span class="tldr-t">핵심 요약</span>
<ul>
<li>단어는 어근 하나로 된 <b>단일어</b>와, 둘 이상이 결합한 <b>복합어</b>로 나뉩니다. 복합어는 다시 <b>합성어</b>와 <b>파생어</b>로 나뉩니다.</li>
<li>합성어 = 어근 + 어근, 파생어 = 접두사 + 어근 또는 어근 + 접미사</li>
<li>세 부분 이상으로 된 단어는 <b>마지막에 결합한 두 부분</b>을 보고 합성어인지 파생어인지 판단합니다.</li>
</ul>
</div>

## 단어의 형성, 단일어와 복합어

| 구분 | 만드는 방법 | 예시 |
| --- | --- | --- |
| 단일어 | 어근 하나 | 하늘, 사과, 바다, 먹다 |
| 합성어 | 어근 + 어근 | 밤나무, 돌다리, 손발, 큰집, 뛰어나다 |
| 파생어 (접두사) | 접두사 + 어근 | 풋사과, 맨손, 덧신, 헛소문, 짓밟다 |
| 파생어 (접미사) | 어근 + 접미사 | 지우개, 먹이, 선생님, 욕심쟁이, 높이다 |

**어근**은 단어에서 실질적인 뜻을 맡은 중심 부분이고, **접사**는 혼자 쓰이지 못하고 어근에 붙어 뜻을 더하거나 품사를 바꾸는 부분입니다. 단어를 쪼갤 때는 어간과 어미처럼 활용으로 바뀌는 부분은 먼저 떼고 보세요. "먹다"의 -다는 어미라 단어의 형성을 따질 때는 "먹-"만 봅니다. 품사 구분이 아직 헷갈린다면 [9품사 글](/info/korean-nine-parts-of-speech/)을 먼저 보세요.

## 접두사 접미사 차이

**접두사는 어근 앞에 붙어 뜻만 더하고, 접미사는 어근 뒤에 붙어 뜻을 더하면서 품사를 바꾸기도 합니다.**

<ul class="cards cards-2">
<li><span class="card-k">접두사</span><b>풋-, 맨-, 덧-, 헛-, 짓-, 새-</b><p>풋사과(덜 익은), 맨손(아무것도 없는), 헛소문(보람 없는)처럼 앞에서 뜻을 더합니다. 대부분 품사는 그대로입니다. 사과(명사) → 풋사과(명사)</p></li>
<li><span class="card-k">접미사</span><b>-개, -이, -님, -쟁이, -질, -롭다</b><p>지우- + -개 → 지우개처럼 동사가 명사로 바뀌는 경우가 많습니다. 높- + -이- → 높이다(형용사 → 동사), 많- + -이 → 많이(형용사 → 부사)</p></li>
<li><span class="card-k">헷갈리는 접미사</span><b>-장이 vs -쟁이</b><p>기술을 가진 사람은 -장이(대장장이, 미장이), 그 밖의 성질이나 버릇을 가진 사람은 -쟁이(멋쟁이, 겁쟁이)를 씁니다.</p></li>
<li><span class="card-k">한자어 접사</span><b>비-, 무-, -적, -화</b><p>비공개, 무관심, 과학적, 현대화처럼 한자어에도 접사가 있습니다. "적"과 "화"는 혼자 쓰이지 못해 접미사입니다.</p></li>
</ul>

## 합성어 파생어 구분법, 세 단계

<ol class="steps">
<li><b>둘로 나누기</b><span>단어를 뜻이 있는 두 덩어리로 나눕니다. 맨손 → 맨 + 손, 손발 → 손 + 발</span></li>
<li><b>각각 혼자 쓰이는지 보기</b><span>"손"과 "발"은 둘 다 혼자 쓰이는 어근이라 손발은 합성어입니다. "맨"은 혼자 쓰이지 않고 다른 말 앞에만 붙으므로 접두사이고, 맨손은 파생어입니다.</span></li>
<li><b>세 부분 이상이면 마지막 결합 보기</b><span>"해돋이"는 해 + 돋- + -이인데, 먼저 "해돋-"이 만들어지고 마지막에 접미사 -이가 붙었으니 <b>파생어</b>입니다. "코웃음"은 코 + (웃- + -음)으로, 마지막 결합이 어근 코와 어근 웃음이니 <b>합성어</b>입니다.</span></li>
</ol>

<div class="callout tip">
<span class="callout-t">관형사와 접두사를 헷갈리지 마세요</span>
<p>"새 옷"의 새는 띄어 쓰는 관형사이고, "새빨갛다"의 새-는 붙여 쓰는 접두사입니다. 띄어 쓸 수 있고 사이에 다른 말이 들어갈 수 있으면 관형사, 늘 붙여 쓰고 뜻을 강조만 하면 접두사로 보면 됩니다.</p>
</div>

## 통사적 합성어와 비통사적 합성어

**합성어가 우리말 문장의 일반적인 단어 배열 방식과 같으면 통사적 합성어, 다르면 비통사적 합성어입니다.** 시험에서는 예시를 주고 둘 중 무엇인지 고르게 하는 문제가 자주 나옵니다.

| 구분 | 만드는 방식 | 예시 |
| --- | --- | --- |
| 통사적 합성어 | 명사 + 명사 | 돌다리, 밤낮, 손발 |
| | 관형사형 + 명사 | 작은형, 큰집, 젊은이 |
| | 용언 + 연결 어미 + 용언 | 돌아가다, 뛰어나다, 들어오다 |
| | 주어·목적어가 결합 (조사 생략) | 힘들다, 본받다, 빛나다 |
| 비통사적 합성어 | 용언 어간 + 명사 (관형사형 어미 없음) | 늦더위, 덮밥, 접칼 |
| | 용언 어간 + 용언 (연결 어미 없음) | 오르내리다, 굳세다, 검붉다 |
| | 부사 + 명사 | 부슬비, 산들바람, 척척박사 |

판단 기준은 "문장에서 이렇게 말할 수 있나"입니다. "작은 형"은 문장에서도 그대로 쓰니 통사적이고, "늦 더위"는 문장에서라면 "늦은 더위"라고 해야 하니 비통사적입니다. 부사는 원래 명사를 꾸미지 못하므로 "부슬비"처럼 부사가 명사 앞에 바로 붙은 합성어는 비통사적 합성어입니다. 문장 안에서 단어가 놓이는 자리는 [문장 성분 글](/info/sentence-components/)에서 함께 확인하세요.

## 확인 문제

여섯 문제로 확인해 보세요. 답을 먼저 정한 뒤 문항을 눌러 확인합니다.

<details class="reveal">
<summary>① "풋사과"는 합성어일까요, 파생어일까요?</summary>
<p><b>파생어</b>. 풋-은 혼자 쓰이지 않는 접두사이고 사과가 어근입니다.</p>
</details>

<details class="reveal">
<summary>② "밤나무"는 합성어일까요, 파생어일까요?</summary>
<p><b>합성어</b>. 밤과 나무 모두 혼자 쓰이는 어근입니다.</p>
</details>

<details class="reveal">
<summary>③ 다음 중 품사가 바뀐 파생어는? (맨손, 덧신, 지우개, 헛소문)</summary>
<p><b>지우개</b>. 동사 어간 지우-에 접미사 -개가 붙어 명사가 되었습니다. 나머지는 접두사가 붙어 품사가 그대로입니다.</p>
</details>

<details class="reveal">
<summary>④ "해돋이"를 마지막 결합 기준으로 나누면 합성어일까요, 파생어일까요?</summary>
<p><b>파생어</b>. (해 + 돋-) + -이로, 마지막에 접미사 -이가 붙었습니다.</p>
</details>

<details class="reveal">
<summary>⑤ 다음 중 비통사적 합성어는? (돌아가다, 작은형, 덮밥, 힘들다)</summary>
<p><b>덮밥</b>. 용언 어간 덮-이 관형사형 어미 없이 명사 밥과 바로 결합했습니다.</p>
</details>

<details class="reveal">
<summary>⑥ "멋장이"와 "멋쟁이" 중 바른 표기는?</summary>
<p><b>멋쟁이</b>. 기술자가 아닌 성질·버릇을 가진 사람에게는 -쟁이를 씁니다.</p>
</details>

①·②를 틀렸다면 단어의 형성 표를, ③·⑥이라면 접두사 접미사 차이를, ④라면 구분법 세 단계를, ⑤라면 통사적·비통사적 합성어 표를 다시 확인하세요. 같은 문법 단원의 [음운 변동](/info/phonological-change/), [높임법](/info/korean-honorifics/)도 함께 복습하면 좋습니다.

## 자주 묻는 질문

### 합성어 파생어는 몇 학년에 배우나요?

교과서마다 다르지만 보통 중학교 1~2학년 문법 단원에서 단어의 짜임으로 배우고, 고등학교 문법에서 통사적·비통사적 합성어와 접사의 기능까지 더 자세히 다룹니다.

### 합성어 파생어 구분법을 한 줄로 정리하면?

둘로 나눴을 때 두 부분이 모두 혼자 쓰이면 합성어, 한쪽이 다른 말에 붙어야만 쓰이는 접사이면 파생어입니다. 세 부분 이상이면 마지막 결합을 봅니다.

### 접두사 접미사 차이는 무엇인가요?

접두사는 어근 앞에 붙어 뜻을 더하고 대부분 품사를 바꾸지 않습니다. 접미사는 어근 뒤에 붙어 뜻을 더하며, 지우개·먹이처럼 품사를 바꾸기도 합니다.

### 통사적 합성어와 비통사적 합성어는 어떻게 구별하나요?

문장에서 쓰는 단어 배열과 같으면 통사적, 다르면 비통사적입니다. 작은형·돌아가다는 통사적, 늦더위·덮밥·오르내리다·부슬비는 비통사적 합성어입니다.
