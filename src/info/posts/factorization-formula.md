**인수분해**는 하나의 다항식을 두 개 이상의 다항식(인수)의 **곱**으로 나타내는 것으로, **곱셈공식을 거꾸로 쓰는 과정**입니다. 중학교 3학년에서는 공통인수 묶기와 네 가지 기본 공식, 그리고 x² 앞에 계수가 붙은 식을 푸는 **크로스(대각선) 방법**을 배우고, 고등학교 1학년에서 세제곱 공식으로 넓어집니다. 어떤 식이든 **공통인수 → 공식 → 크로스 → 치환** 순서로 확인하면 대부분 풀립니다.

<div class="tldr">
<span class="tldr-t">핵심 요약</span>
<ul>
<li>인수분해는 항상 <b>공통인수를 먼저 묶고</b> 시작합니다. 빠뜨리면 답이 끝까지 인수분해되지 않습니다.</li>
<li>항이 두 개면 <b>합차 공식</b>, 세 개면 <b>완전제곱식이나 x²+(a+b)x+ab</b>, x² 계수가 1이 아니면 <b>크로스 방법</b>을 떠올립니다.</li>
<li>같은 덩어리가 반복되면 <b>한 글자로 바꿔(치환)</b> 간단한 식으로 만든 뒤 인수분해합니다.</li>
</ul>
</div>

## 중3 인수분해 공식 한눈에 보기

| 공식 | 인수분해 | 예 |
| --- | --- | --- |
| 공통인수 | ma + mb = m(a + b) | 3x² + 6x = 3x(x + 2) |
| 완전제곱식 (합) | a² + 2ab + b² = (a + b)² | x² + 6x + 9 = (x + 3)² |
| 완전제곱식 (차) | a² − 2ab + b² = (a − b)² | x² − 10x + 25 = (x − 5)² |
| 합차 공식 | a² − b² = (a + b)(a − b) | 4x² − 25 = (2x + 5)(2x − 5) |
| 이차식 (x² 계수 1) | x² + (a + b)x + ab = (x + a)(x + b) | x² + 5x + 6 = (x + 2)(x + 3) |
| 이차식 (x² 계수 ≠ 1) | acx² + (ad + bc)x + bd = (ax + b)(cx + d) | 6x² + 7x + 2 = (2x + 1)(3x + 2) |

<div class="callout tip">
<span class="callout-t">완전제곱식인지 빨리 알아보는 법</span>
<p>x² + bx + c에서 <b>(x의 계수 ÷ 2)² = 상수항</b>이면 완전제곱식입니다. x² + 6x + 9는 (6 ÷ 2)² = 9이므로 (x + 3)²입니다. 이 성질은 이차방정식과 이차함수의 꼭짓점을 구할 때도 그대로 쓰입니다.</p>
</div>

## x² + (a + b)x + ab는 어떻게 인수분해하나요?

**곱해서 상수항, 더해서 x의 계수가 되는 두 수를 찾습니다.** x² − x − 12라면 곱해서 −12, 더해서 −1이 되는 두 수는 −4와 3이므로 (x − 4)(x + 3)입니다.

두 수를 찾을 때는 **상수항의 부호부터** 보세요. 상수항이 양수면 두 수의 부호가 같고(x의 계수 부호를 따름), 음수면 두 수의 부호가 서로 다릅니다. 이렇게 범위를 좁히면 후보를 몇 개만 확인해도 답이 나옵니다.

## 인수분해 크로스(대각선) 방법

x² 앞에 1이 아닌 계수가 붙으면 **크로스 방법**을 씁니다. x²의 계수와 상수항을 각각 두 수의 곱으로 나눠 세로로 적고, **대각선으로 곱한 값의 합이 x의 계수**가 되는 조합을 찾습니다.

## 인수분해하는 순서

문제를 받으면 아래 순서대로 확인하면 빠뜨리는 단계가 없습니다.

<ul class="cards">
<li><span class="card-k">1단계</span><b>공통인수 묶기</b><p>3x² − 12 → 3(x² − 4)처럼 먼저 묶습니다. 이 단계를 건너뛰면 2x² − 8 = (2x + 4)(x − 2)처럼 덜 인수분해된 답이 나옵니다.</p></li>
<li><span class="card-k">2단계</span><b>항의 개수로 공식 고르기</b><p>항이 두 개면 합차 공식, 세 개면 완전제곱식이나 x² + (a + b)x + ab를 먼저 확인합니다.</p></li>
<li><span class="card-k">3단계</span><b>계수가 있으면 크로스</b><p>x² 앞에 1이 아닌 수가 있고 공통인수로 묶이지 않으면 크로스 방법으로 조합을 찾습니다.</p></li>
<li><span class="card-k">4단계</span><b>반복되는 덩어리는 치환</b><p>(x + 1)² + 3(x + 1) + 2는 x + 1 = t로 바꾸면 t² + 3t + 2 = (t + 1)(t + 2)이고, 다시 되돌리면 (x + 2)(x + 3)입니다.</p></li>
</ul>

마지막에는 답을 **다시 전개해 원래 식이 나오는지** 확인하세요. 인수분해는 전개로 바로 검산할 수 있는 몇 안 되는 단원입니다.

## 고1 인수분해 공식: 세제곱

고등학교 1학년 공통수학에서는 세제곱이 들어간 공식이 추가됩니다. 중3 공식과 함께 외워 두면 다항식 단원 전체가 수월해집니다.

| 공식 | 인수분해 |
| --- | --- |
| 세제곱의 합 | a³ + b³ = (a + b)(a² − ab + b²) |
| 세제곱의 차 | a³ − b³ = (a − b)(a² + ab + b²) |
| 완전세제곱식 (합) | a³ + 3a²b + 3ab² + b³ = (a + b)³ |
| 완전세제곱식 (차) | a³ − 3a²b + 3ab² − b³ = (a − b)³ |

세제곱의 합·차 공식은 **두 번째 괄호 안 가운데 항의 부호가 앞 괄호와 반대**라는 점만 기억하면 헷갈리지 않습니다. 인수분해가 단단하면 이후 [피타고라스 정리](/info/pythagorean-theorem/)처럼 식을 세워 푸는 단원과 이차방정식에서 계산이 빨라집니다.

## 확인 문제

여섯 개의 식을 인수분해해 보세요. 답을 먼저 정한 뒤 문항을 눌러 확인합니다.

<details class="reveal">
<summary>① x² + 6x + 9</summary>
<p><b>(x + 3)²</b>. (6 ÷ 2)² = 9이므로 완전제곱식입니다.</p>
</details>

<details class="reveal">
<summary>② 4x² − 25</summary>
<p><b>(2x + 5)(2x − 5)</b>. (2x)² − 5² 꼴이므로 합차 공식을 씁니다.</p>
</details>

<details class="reveal">
<summary>③ x² − x − 12</summary>
<p><b>(x − 4)(x + 3)</b>. 곱해서 −12, 더해서 −1이 되는 두 수는 −4와 3입니다.</p>
</details>

<details class="reveal">
<summary>④ 2x² + 5x + 3</summary>
<p><b>(2x + 3)(x + 1)</b>. 크로스로 2x × 1 = 2x, x × 3 = 3x를 더하면 5x입니다.</p>
</details>

<details class="reveal">
<summary>⑤ 3x² − 12</summary>
<p><b>3(x + 2)(x − 2)</b>. 공통인수 3을 먼저 묶으면 3(x² − 4)이고, 괄호 안을 합차 공식으로 인수분해합니다.</p>
</details>

<details class="reveal">
<summary>⑥ (고1) x³ − 8</summary>
<p><b>(x − 2)(x² + 2x + 4)</b>. x³ − 2³ 꼴이므로 세제곱의 차 공식을 씁니다.</p>
</details>

⑤번처럼 공통인수를 빠뜨려 틀렸다면 1단계 습관을, ④번이 막혔다면 크로스 방법의 조합 바꾸기를 다시 연습하세요. 일차식과 그래프의 기초가 흔들린다면 [일차함수 그래프 글](/info/linear-function-graph/)부터 복습하는 것도 좋습니다.

## 자주 묻는 질문

### 인수분해는 중학교 몇 학년에서 배우나요?

중학교 3학년 1학기 다항식의 곱셈과 인수분해 단원에서 배웁니다. 고등학교 1학년 공통수학에서 세제곱 공식과 복잡한 식의 인수분해로 이어지고, 이차방정식과 이차함수를 푸는 데 계속 쓰입니다.

### 곱셈공식과 인수분해 공식은 어떻게 다른가요?

같은 등식을 반대 방향으로 쓰는 것입니다. 곱셈공식은 (a + b)² = a² + 2ab + b²처럼 괄호를 풀어 전개하는 방향이고, 인수분해는 a² + 2ab + b² = (a + b)²처럼 곱의 꼴로 묶는 방향입니다. 곱셈공식을 정확히 외우면 인수분해 공식도 함께 해결됩니다.

### 인수분해 크로스 방법은 언제 쓰나요?

x² 앞에 1이 아닌 계수가 있고 공통인수로 묶이지 않는 이차식에 씁니다. 6x² + 7x + 2처럼 x²의 계수와 상수항을 각각 두 수의 곱으로 나눈 뒤, 대각선 곱의 합이 x의 계수가 되는 조합을 찾습니다.

### 인수분해가 끝났는지 어떻게 알 수 있나요?

각 인수를 더 이상 인수분해할 수 없을 때까지 나눴는지 확인합니다. 특히 공통인수를 먼저 묶었는지, 괄호 안에 합차 공식이나 완전제곱식이 남아 있지 않은지 보세요. 답을 다시 전개해 원래 식이 나오면 계산도 맞은 것입니다.
