**일차부등식**은 부등호의 한쪽으로 모든 항을 옮겨 정리했을 때 (x에 대한 일차식) > 0, < 0, ≥ 0, ≤ 0 가운데 하나의 꼴이 되는 부등식입니다. 풀이는 일차방정식과 거의 같지만 딱 하나가 다릅니다. **양변에 음수를 곱하거나 음수로 나누면 부등호의 방향이 바뀝니다.** 중학교 2학년 1학기에 배우며, 시험에서는 이 방향 실수와 수직선 표시, 개수·거리·농도 활용 문제가 가장 많이 나옵니다.

<div class="tldr">
<span class="tldr-t">핵심 요약</span>
<ul>
<li>부등식의 성질: 같은 수를 더하거나 빼도, 양수를 곱하거나 나눠도 방향 그대로. <b>음수를 곱하거나 나누면 방향이 반대로</b>.</li>
<li>일차부등식 풀이 순서: 괄호 풀기 → 계수 정수로 → 이항 → 정리 → x의 계수로 나누기</li>
<li>수직선에서 &lt;, &gt;는 <b>빈 동그라미(○)</b>, ≤, ≥는 <b>채운 동그라미(●)</b>로 표시합니다.</li>
</ul>
</div>

## 부등식의 성질, 왜 방향이 바뀔까?

| 성질 | 예 (a < b일 때) | 방향 |
| --- | --- | --- |
| 양변에 같은 수를 더하거나 빼기 | a + 3 < b + 3, a − 3 < b − 3 | 그대로 |
| 양변에 같은 양수를 곱하거나 나누기 | 2a < 2b, a/2 < b/2 | 그대로 |
| 양변에 같은 음수를 곱하거나 나누기 | −2a > −2b, a/(−2) > b/(−2) | **반대로** |

2 < 5에 −1을 곱하면 −2와 −5가 되는데, 수직선에서 −2가 −5보다 오른쪽에 있으니 −2 > −5입니다. 음수를 곱하면 수의 크기 순서가 뒤집히기 때문에 부등호도 뒤집어야 합니다. 이 원리만 이해하면 외우지 않아도 실수가 줄어듭니다.

## 일차부등식 풀이 순서

<ol class="steps">
<li><b>괄호 풀기</b><span>분배법칙으로 괄호를 풉니다. 3(x − 2) > x + 4 → 3x − 6 > x + 4</span></li>
<li><b>계수를 정수로</b><span>소수면 10, 100을, 분수면 분모의 최소공배수를 양변에 곱합니다. 양수를 곱하니 방향은 그대로입니다.</span></li>
<li><b>이항하기</b><span>x가 있는 항은 왼쪽, 수는 오른쪽으로 옮깁니다. 3x − x > 4 + 6</span></li>
<li><b>정리하기</b><span>동류항끼리 계산합니다. 2x > 10</span></li>
<li><b>x의 계수로 나누기</b><span>x > 5. 계수가 음수라면 이 단계에서 부등호 방향을 바꿉니다.</span></li>
</ol>

<div class="callout tip">
<span class="callout-t">방향 실수를 막는 습관</span>
<p>이항할 때 x가 있는 항을 계수가 양수가 되는 쪽으로 모으면 마지막에 음수로 나눌 일이 없습니다. 예를 들어 −3x + 2 ≥ x − 6은 x항을 오른쪽으로 모아 8 ≥ 4x, 즉 2 ≥ x(x ≤ 2)로 풀면 방향을 바꿀 필요가 없습니다.</p>
</div>

방정식 풀이에서 이항과 동류항 정리가 아직 헷갈린다면, 같은 원리로 푸는 [근의 공식 글](/info/quadratic-formula/)의 이차방정식 풀이 순서와 비교해 보는 것도 도움이 됩니다.

## 수직선 표시와 특별한 해

**부등식의 해는 수직선 위에 범위로 나타내고, 경계의 수를 포함하는지에 따라 동그라미 모양이 다릅니다.**

<ul class="cards cards-2">
<li><span class="card-k">x &gt; 2</span><b>빈 동그라미 + 오른쪽</b><p>2는 해가 아니므로 ○로 표시하고 오른쪽으로 화살표를 긋습니다.</p></li>
<li><span class="card-k">x ≤ −1</span><b>채운 동그라미 + 왼쪽</b><p>−1도 해이므로 ●로 표시하고 왼쪽으로 화살표를 긋습니다.</p></li>
<li><span class="card-k">해가 없는 경우</span><b>0·x &gt; 3</b><p>x에 어떤 수를 넣어도 0 > 3이 되어 거짓이니 해가 없습니다. 2(x + 1) > 2x + 5처럼 정리했을 때 x가 사라지는 문제에서 나옵니다.</p></li>
<li><span class="card-k">모든 수가 해</span><b>0·x &gt; −2</b><p>어떤 x를 넣어도 0 > −2가 참이니 모든 수가 해입니다.</p></li>
</ul>

## 일차부등식 활용, 개수·거리·농도

**활용 문제는 "이하·이상·넘지 않게·적어도" 같은 말을 부등호로 바꾸는 것부터 시작합니다.** "넘지 않는다"는 ≤, "적어도"는 ≥입니다.

| 유형 | 문제 | 식과 답 |
| --- | --- | --- |
| 개수 | 800원짜리 빵을 3,000원짜리 상자에 담아 전체 10,000원 이하로 산다. 빵은 몇 개까지? | 800x + 3000 ≤ 10000 → x ≤ 8.75 → 8개까지 |
| 거리·속력 | 갈 때 시속 3km, 올 때 시속 4km로 걸어 2시간 안에 돌아오려면 몇 km까지 갈 수 있나? | x/3 + x/4 ≤ 2 → 7x ≤ 24 → x ≤ 24/7 (약 3.4km) |
| 농도 | 8% 소금물 300g에 물을 더해 6% 이하로 만들려면 물을 몇 g 이상 넣어야 하나? | 소금 24g, 24/(300 + x) ≤ 6/100 → x ≥ 100 → 100g 이상 |

농도 문제는 **물을 더해도 소금의 양은 그대로**라는 점이 핵심입니다. 먼저 소금의 양을 구하고, 전체 소금물의 양만 x를 넣어 바꾸면 식이 단순해집니다. 개수 문제에서 답이 소수로 나오면 문제 상황에 맞게 자연수로 정리해야 한다는 점도 잊지 마세요.

## 확인 문제

여섯 문제로 확인해 보세요. 답을 먼저 정한 뒤 문항을 눌러 확인합니다.

<details class="reveal">
<summary>① 3x − 5 > 7의 해는?</summary>
<p><b>x > 4</b>. 3x > 12에서 양변을 3으로 나눕니다.</p>
</details>

<details class="reveal">
<summary>② −2x + 1 ≤ 7의 해는?</summary>
<p><b>x ≥ −3</b>. −2x ≤ 6에서 음수 −2로 나누므로 부등호 방향이 바뀝니다.</p>
</details>

<details class="reveal">
<summary>③ 0.3x − 0.5 < 0.1x + 0.7의 해는?</summary>
<p><b>x < 6</b>. 양변에 10을 곱하면 3x − 5 < x + 7, 2x < 12입니다.</p>
</details>

<details class="reveal">
<summary>④ x/2 − 1 ≥ x/3의 해는?</summary>
<p><b>x ≥ 6</b>. 양변에 6을 곱하면 3x − 6 ≥ 2x입니다.</p>
</details>

<details class="reveal">
<summary>⑤ 2(x + 1) > 2x + 5의 해는?</summary>
<p><b>해가 없다</b>. 정리하면 0·x > 3이 되어 어떤 x도 만족하지 않습니다.</p>
</details>

<details class="reveal">
<summary>⑥ x ≥ −3을 수직선에 나타낼 때 −3에 찍는 동그라미는?</summary>
<p><b>채운 동그라미(●)</b>. 등호가 있어 −3도 해에 포함되고, 오른쪽으로 화살표를 긋습니다.</p>
</details>

①·③·④를 틀렸다면 풀이 순서를, ②라면 부등식의 성질을, ⑤·⑥이라면 수직선 표시와 특별한 해를 다시 확인하세요. 같은 중2 1학기 단원인 [일차함수 그래프 글](/info/linear-function-graph/)도 함께 복습하면 좋습니다.

## 자주 묻는 질문

### 일차부등식은 몇 학년에 배우나요?

중학교 2학년 1학기에 일차부등식과 활용을 배우고, 고등학교 1학년에서 연립부등식과 절댓값이 있는 부등식으로 넓어집니다.

### 일차부등식 풀이에서 가장 많이 틀리는 곳은?

양변을 음수로 나누면서 부등호 방향을 바꾸지 않는 실수입니다. x항을 계수가 양수가 되는 쪽으로 모으면 이 실수를 줄일 수 있습니다.

### 일차부등식 활용 농도 문제는 어떻게 세우나요?

먼저 소금의 양을 구합니다. 물을 더하거나 증발시켜도 소금의 양은 그대로이므로, (소금의 양) ÷ (바뀐 소금물의 양) × 100이 조건의 농도 이하·이상이 되도록 식을 세웁니다.

### 해가 없는 일차부등식은 어떻게 알아보나요?

정리했을 때 x가 사라지고 0·x > 3처럼 항상 거짓인 식이 남으면 해가 없습니다. 반대로 0·x > −2처럼 항상 참이면 모든 수가 해입니다.
